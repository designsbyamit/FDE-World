# Collections Agent Portal 1.1

A standalone, client-side prototype for a collector-first collections experience.

## Run

Open `index.html` in a modern browser. No build step or dependencies required.

## Prototype scope

- Prioritised My Worklist and Today's Focus
- Segment switching with context summaries
- Customer 360 with invoices and activity history
- Simulated email composer for reminders and invoice copies
- Promise-to-pay, dispute capture, scheduling, and escalation request
- Group Worklist with assignment demo

All data is fictional. Actions update local prototype state only; no emails are sent and no live SAP services are connected.
