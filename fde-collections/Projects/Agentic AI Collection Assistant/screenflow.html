FLOW 1 Collections Agent Experience
Collections Agent
Collections Worklist
Agent opens the worklist filtered to "Action Required" cases, sorted by priority. Agent clicks a customer row to open the collection case detail.
Flow 1a Email Customer
Collections Agent
Collection Case Detail
Agent opens a case. AI summary and suggested actions are shown. Agent clicks "Email Customer" to open the email panel.
Collections Agent
Email Panel — Draft
Slide-in panel opens with a pre-populated subject and AI-drafted body. Agent selects tone (Neutral, Professional, Friendly, Firm) and edits if needed, then clicks Send.
System
Email Sent
Email is sent to the customer. The communication history updates with a timestamped entry showing the message summary and tone used.
Flow 1b Call Customer
Collections Agent
Collection Case Detail
Agent opens a case. AI summary and suggested actions are shown. Agent clicks "Call Customer" to open the call script panel.
Collections Agent
Call Script Panel
Slide-in panel opens with an AI-generated call script tailored to the account's overdue balance and history. Agent uses the script as a guide during the call.
System
Call Attempt Logged
Call attempt is recorded in the communication history. Agent can add notes via the Notes panel after the call.
Flow 1c Review and Approve
Collections Agent
Collection Case Detail
Agent opens a case. Reviews overdue invoices, account KPIs, open items, payment history, and disputes. Agent clicks "Approve" on the AI-suggested action card.
System
Action Approved
The approved action is executed (e.g. ServiceNow ticket created, follow-up scheduled). Action is recorded in the communication history.
FLOW 2 Administrator Experience
Administrator
Administration — System Configuration
Admin opens the Administration page. System Configuration tab is shown by default with a table of integrations (Office365, SAP FSCM, Databricks, ServiceNow) and their connection status.
Administrator
Connect Integration
Admin clicks "Connect" on a row (e.g. SAP FSCM). Authentication and configuration steps are completed to bring the integration online.
Administrator
Manage Users
Admin clicks "SAP Cloud IAS" to open identity and access management. Users can be added, removed, or have their permissions updated.
