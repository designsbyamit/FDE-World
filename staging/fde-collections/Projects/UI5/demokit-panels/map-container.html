Map Container
A map container with a description panel, fullscreen toggle, and an analytic map for geographic bubble chart data. No Web Components equivalent — rendered using Leaflet.js with OpenStreetMap tiles. Equivalent to sap.ui.vk.MapContainer + sap.ui.vbm.AnalyticMap.
Analytic Map with Description Panel Leaflet.js · OpenStreetMap · sap.ui.vk.MapContainer
Description ▼
The Map Container provides a predefined feature set tailored for map usage. The application can integrate additional application-specific buttons within the transparent toolbar. The map container also provides a list panel stack which can be used for a legend or other application-specific content.
