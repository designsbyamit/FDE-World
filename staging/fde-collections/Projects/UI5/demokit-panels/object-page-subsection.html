Object Page SubSection
An Object Page with sub-sections that can be individually expanded or collapsed. The first sub-section is always expanded; others default to collapsed but can be toggled. Equivalent to sap.uxap.ObjectPageSubSection with Expanded/Collapsed mode — rendered with ui5-dynamic-page.
