# Sample Project

## Project Overview
A single-page sample demonstrating the Worklist pattern — an AI-assisted supplier onboarding tool that surfaces pending review items, shows submission status, and provides AI-driven recommendations. Use this as a starting point to clone and adapt for your own project.

## Pages
- `sample.html` — Supplier Onboarding worklist showing suppliers across regions and categories

## Persona
- Reviewer is the procurement or onboarding manager reviewing supplier submissions.
