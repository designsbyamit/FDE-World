Line Height
--sapContent_LineHeight 1.4
SAP Fiori uses a line-height of 1.4 as the standard for body text. This ensures comfortable reading across all screen sizes and text lengths, providing adequate space between lines without excessive gaps. Use this value whenever setting line-height in application content areas.
