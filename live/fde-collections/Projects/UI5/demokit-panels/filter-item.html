Filter Item
A child element of Filter Bar, representing one filterable field with a label and input.
ui5-filter-item is used as a slot child within ui5-filter-bar (from @ui5/webcomponents-fiori). It wraps any input component and adds a filter label. The examples below show typical configurations as they appear inside a Filter Bar.
